# Calculadora de Custos Imóveis

Aplicativo móvel para consulta, organização e regularização de gastos relacionados a imóveis.

## 📱 Plataformas Suportadas

- ✅ iOS
- ✅ Android

## 🛠️ Tecnologia

- **Framework**: Flutter (Dart)
- **Razão**: Flutter é a tecnologia mais rápida para desenvolvimento cross-platform com melhor performance, hot reload, e UI consistente em ambas as plataformas

## 📋 Funcionalidades Principais

- 📊 Registro e consulta de gastos do imóvel
- 💰 Categorização de despesas
- 📈 Relatórios e análises de gastos
- 🔍 Filtros por período
- 💾 Exportação de dados
- 🏠 Suporte para múltiplos imóveis

## 🚀 Quick Start

### Pré-requisitos

- Flutter SDK (https://flutter.dev/docs/get-started/install)
- Dart SDK (incluído no Flutter)
- Android Studio ou Xcode (para emuladores)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/pchuqui/calculadora-de-custos-imoveis.git
cd calculadora-de-custos-imoveis

# Instale as dependências
flutter pub get

# Execute o app
flutter run
```

### Desenvolvimento

```bash
# Hot reload durante desenvolvimento
flutter run

# Build para iOS
flutter build ios

# Build para Android
flutter build apk
```
